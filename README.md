# 부산대 입시·진학 통계

전국 고교 졸업자 대학 진학률 추이와 부산대학교 수시·정시 입시 커트라인을 한 페이지로 정리한 정적 대시보드입니다.

- 페이지: https://themoka7.github.io/AI_Maestro_Self_07/

## 내용

| 섹션 | 데이터 |
|---|---|
| ① 전국 대학 진학률 | 2008 정점(83.8%) → 2017 저점(68.9%) → 2024 73.6% |
| ② 부산대 경쟁률 | 2025·2026학년도 수시/정시 |
| ③ 부산 일반고 4년제 진학률 | 2023 77.72% → 2024 76.54% |
| ④ 수시 학생부교과 70% 컷 | 2025·2026학년도 모집단위별 |
| ⑤ 정시 백분위 70% 컷 | 2025학년도 모집단위별 |

## 데이터 신뢰등급

모든 수치는 `site/data.js` 에 출처 URL과 함께 들어 있습니다.

- **A** 정부·공공기관 발표 또는 그것을 직접 인용한 언론 보도
- **B** 입시기관(진학사) 집계
- **C** 개인 입시 블로그 집계 — 공식 자료와 대조 전까지 참고용

출처마다 값이 다른 항목은 `alt` 에 다른 값을 남겼습니다.
부산대 입학처 공식 입시결과, KESS 교육통계 원자료를 확보하면 `data.js` 만 교체하면 됩니다.

## 구조

```
site/
  index.html   # 화면 (의존성 없는 HTML/CSS/SVG)
  data.js      # 데이터 + 출처
.github/workflows/pages.yml   # site/ 를 GitHub Pages 로 배포
```

빌드 단계가 없습니다. 로컬에서는 `site/index.html` 을 브라우저로 열면 됩니다.

## Pages 설정

저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 지정하면,
`main` 또는 작업 브랜치에 push 할 때마다 자동 배포됩니다.
